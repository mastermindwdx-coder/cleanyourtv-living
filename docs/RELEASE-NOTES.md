# CleanYourTV 客厅版 · 首个实验版

**清爽的电视首页，再加上 YouTube。**

这个项目首先保留 CleanYourTV 的简洁主页、应用库与排序、主题壁纸和闲置时钟等核心体验，并在指定小米电视上补齐遥控器、应用入口、布局与恢复细节。

我们补齐的日常细节包括：

- 三下 Home，在自己的主页和原系统之间来回切换。
- 一个＋添加常用应用，长按 OK 移出主页，软件本身保留。
- 底栏给壁纸让位置，焦点移动不再把画面染成 App 的颜色。
- 主页与闲置时钟共用自己的图集，也保留可选的本地4K视频背景能力。
- 方向键不连跳，中文布局补齐，改造前有快照，恢复时识别外部冲突。
- 可选的个人网络配置转换、电视状态页和 SmartTube 中文错误提示。
- 把踩坑过程整理成 Agent 适配指南，让其他人从自己的电视出发，而不是复制作者家里的配置。

**在这个基础上，我们进一步打通了小米电视看 YouTube：** 通过 SmartTube 搜索和实际观看内容，登录本人账号后加载订阅、播放列表／稍后观看和账号历史。1080p60 AVC 与 1440p24 VP9 有实播记录。

实现方法包括个人 Clash/Mihomo 配置迁移、电视端 VPN、影音入口、中文错误提示和可复用的排查流程。网络客户端是 Clash Meta for Android，影音与账号能力来自 SmartTube；个人网络与账号由使用者提供，Google 官方 YouTube App 的设备兼容限制仍然存在。

这是基于 CleanYourTV 与 Aerial 定制经验的独立实践分支；原界面、时钟、应用库、轮换等基础归上游。功能、来源、证据逐项公开，见 FEATURES.md。

目前仅指定小米型号/固件有实机基线。保留省电待机时仍有原首页短暂闪现；静态UI1080p、4K60播放未通过；其他机型、冷启动、长期稳定和完整实机恢复尚待各自验证。没有去掉视频App内广告，不带电影壁纸、网络订阅、账号，也不是官方YouTube或Netflix兼容方案。

这一版以源码、构建与适配方法交付。先普通启动，再接管Home；所有系统变更保留恢复依据。公开前请核对当前 VERIFICATION.md 与 PUBLISH-CHECKLIST.md。
