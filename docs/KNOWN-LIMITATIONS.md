# 已知限制与验证状态

| 项目 | 状态 / 当前边界 |
|---|---|
| 三连 Home 双向切换、方向键单步、＋和移除 | 作者私人功能基线实机通过；公开构建未安装到其电视 |
| 省电唤醒 | 自动回新主页已验证，但先短暂显示小米原首页；没有零闪现方案 |
| 断电冷启动、VPN 冷启动/待机自动恢复 | 未完整验收；本轮不处理 |
| 多小时播放、多轮待机与频繁切应用 | 未长期测试 |
| HDMI 真实图像和声音 | 本轮没有实际开启 PS5 验证；原输入系统保留，映射不等于实播 |
| 静态壁纸 | 私有图集及钟页可见；源图 4K，静态 UI 1080p；完整 20 分钟四图轮换未计时 |
| 动态壁纸 | 临时 4K 素材解码与释放有验证；正式使用静态，不附带任何视频 |
| 完整实机恢复 | 尚未执行；有首次快照、冲突、断连/重试自动测试；不是整机镜像 |
| SmartTube | 登录、频道、订阅/列表/历史、1080p60 实播通过；4K60未通过，403不保证消失；上游服务会变化 |
| 默认主题及签名 | 公开版本采用中性默认，无原私人图形；版本/签名/个人覆盖配置不同，不能当作同一份已验电视APK |
| 其他型号或固件 | 未验证，使用者 Agent 逐项诊断；不承诺全部兼容 |
| 广告 | 只针对首页布局与已核对原厂屏保；不处理视频片头、中插、画面植入 |
| Netflix、电视 Codex | 前者暂停、后者移除；不作为公开版能力 |

以上不隐藏在小字里。宣传时与 [功能清单](FEATURES.md) 配套，不能用单台设备的“通过”覆盖未测项目。详细模型与固件状态见 [兼容范围](LOCAL-FORK-COMPATIBILITY.md)。
