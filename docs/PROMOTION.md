## 项目介绍正文

我们先以 CleanYourTV 为基础，把小米电视变成清爽、顺手的个人主页：简洁界面、常用应用、个人壁纸和闲置时钟。这些核心能力来自 CleanYourTV，我们再补齐三连 Home 双向切换、加号添加应用、长按移除、方向键去重和恢复工具。

在这个基础上，我们进一步打通了小米电视观看 YouTube 的流程：通过 SmartTube 搜索视频、打开博主频道并实际播放，登录自己的账号后，接上订阅、播放列表、稍后观看和历史记录。1080p60 已有实际播放证据。

实现时，把本人已有的 Clash/Mihomo 配置整理成电视副本，在电视端连接个人 VPN，再由本人在手机浏览器完成 Google 授权。我们把配置转换、中文错误提示、实际排查经验和逐机适配指南一起整理进开源候选，让下一位使用者的 Agent 能根据自己的电视继续处理。

这条路线使用 Clash Meta for Android 与 SmartTube；不是 Google 官方 YouTube App 的认证方案。当前只在指定小米型号/固件验证，4K60及待机网络自动恢复仍待验收，个人节点与账号不随项目提供。

## 六句卖点

1. CleanYourTV 的简洁主页，把时间、壁纸和常用应用放到前面。
2. 应用自由选择，主页与闲置时钟用自己的图集。
3. 三下 Home 来回切换，加号添加、长按移除，遥控器操作更顺手。
4. 在这套体验上，进一步看起 YouTube 内容。
5. 登录自己的账号，接上订阅、播放列表和历史。
6. 个人网络有配置方法，改造有备份，下一位使用者的 Agent 有适配指南。
