# 让电视更像自己的客厅：完整功能与改动

每一行都连接用户感受、实现位置和验证边界。“新增”指本实践分支相对固定 CleanYourTV 基线的改动，不表示相关概念从未存在。

**对外介绍顺序：先讲 CleanYourTV 的核心桌面体验及我们的使用细节，再讲在此基础上打通小米电视看 YouTube。** 简洁主页、应用库、排序、壁纸与闲置时钟来自上游；三连 Home、交互修正、恢复和逐机方法是本地实践。在这些基础上，进一步展示 YouTube 实播与本人账号登录，个人 VPN 放在实现方法里说明，见 [详细说明](OPTIONAL-MODULES.md)。

## 保留但不放进公开分发的个人选择

作者选用四张怪兽公司静态图；主页和时钟共同轮换。公开的是图集能力与预设，不分发电影图片。作者曾要求 SmartTube 使用 YouTube 外观图标；这是个人外观选择，公开补丁剔除该图像改动，保持 SmartTube 身份与上游图形。公开介绍不把换图标称为“官方 YouTube”。

## 已经退出这版的内容

电视端 Codex、电脑桥接、配对与后台轮询已移除；Netflix 暂停。视频 App 片头/中插/植入处理、HDMI 新提示或实时预览不在本版内。省电唤醒闪现、4K60播放、长时间稳定性等保持 [已知限制](KNOWN-LIMITATIONS.md)，初始候选只做开源整理；后续网络与网速更新的独立实播范围见[播放与自动选线](PLAYBACK-NETWORK.md)。
