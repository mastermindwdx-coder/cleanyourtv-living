# 本定制分支的实际兼容范围

本分支基于 CleanYourTV `f592b6d2db0cfa0e28779660f25ff65386a5ff9b`；主页守护等迁移自此前基于 Aerial `2f54aafa3aba8ba6f8d588b6983a45198cea12b4` 的本地定制。原作者与 MIT/OFL 许可证保留。

| 设备 | 系统/固件 | 已验证 | 已知限制 |
|---|---|---|---|
| 小米 MiTV-MFTR0（S Pro 75 Mini LED） | Android 14 / OS3.0.101.0.UFTMATV / ARMv7 | 新主页、实体遥控器三连 Home 双向切换、方向键单步、应用加号/长按移除、静态壁纸与闲置时钟 | 省电唤醒先露原首页；静态 UI 1080p；完整实机恢复、冷启动和 HDMI 实播未验收 |
| 其他电视或上述型号的其他固件 | 未验证 | 可按 Agent 指南逐层测试普通启动与基础界面 | 不直接运行小米专用 setup-home，不宣称三连 Home/去屏保已兼容 |

维护者只有上述实测设备。**多机型测试不是首个实验版发布的前提，准确标注边界和可恢复的适配流程是前提。** 使用者的 Agent 按 [适配指南](LOCAL-FORK-AGENT-GUIDE.md) 诊断、实现必要适配并提交本机结果。Agent 能协助解决问题，但不保证绕过厂商限制或每台电视均可接管 Home。

## 不属于当前承诺

- 不保证所有系统广告消失。当前完成的是个人主页替代和已核实的原厂影视屏保停用；原系统桌面保留。
- 不处理视频 App 片头/中插/画面植入，不新增 HDMI 实时预览。
- 不承诺亮屏第一帧就是新主页，也不默认改变用户省电待机。
- 不附赠影片、会员、网络订阅、账号或受保护设备认证。
- Netflix 暂停，电视 Codex 已移除。SmartTube 与个人网络是可选独立客户端。
- 不附带维护者私有壁纸、Google 品牌图形改包、个人连接配置与签名密钥。

## 状态升级规则

新机型从 `not_tested` 开始。Agent 自报编译通过只能记构建通过；遥控器需要实体操作，HDMI 需要真实画面和声音，冷启动与恢复需要实际执行。将模型/固件和各功能分别记录，不用一个“兼容”掩盖部分失效。固件升级后旧结果继续作为历史，新的当前状态待复核。

本机基线的可读记录见 [设备 JSON](device-profiles/xiaomi-mitv-mftr0.json)。新增机型复制 [设备模板](device-profiles/device-profile.example.json)，反馈用 [报告模板](DEVICE-REPORT-TEMPLATE.md)。
